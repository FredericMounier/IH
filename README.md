# Projet Divalto IH

Nouveau projet Divalto - Structure de base.

## Structure du projet

```
IH/
├── src/           # Code source principal
├── config/        # Fichiers de configuration
├── docs/          # Documentation
└── tests/         # Tests
```

## Prérequis

- Divalto ERP (version compatible)
- Accès au serveur Divalto

## Installation

1. Cloner le dépôt
2. Configurer les paramètres dans `config/`
3. Déployer les modules selon la documentation

## Configuration

Copier `config/config.example.ini` vers `config/config.ini` et renseigner les paramètres de connexion.
